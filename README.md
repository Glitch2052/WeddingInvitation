# Wedding Invitation

Fresh GitHub Pages wedding invitation prototype.

## Current features

- Animated opening invitation cover
- Tap-to-open music start
- Constant viewport-wide falling petals and colored daisies
- Scroll-triggered section reveals
- Scroll-driven bride/groom prototype: pink rectangle + blue rectangle move together as the user scrolls
- Venue / Google Maps button
- Final closing message:
  - YOUR PRESENCE MATTERS,
  - We can't wait to celebrate with you.
- No RSVP section

## Structure

- `index.html` — page structure and editable invitation content
- `css/style.css` — visual styling
- `css/animations.css` — animations
- `js/invitation.js` — opening/music/interaction and couple scroll animation
- `js/flowers.js` — constant falling flower particles
- `js/scroll.js` — scroll reveal animations
- `audio/kudmayi.mp3` — background music
- `images/` — reserved for future artwork
