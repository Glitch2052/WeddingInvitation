# Nikita & Kamlesh Wedding Invitation

5-page mobile-first wedding invitation.

## Current design
- No WebGL background feathering or permanent edge blur.
- Background images are rendered normally with responsive CSS `background-image`.
- Fonts:
  - Cormorant SC — display/headings
  - Cormorant Garamond — body
  - Meddon — script accents
  - Great Vibes — bride/groom names
  - Noto Serif Devanagari — Sanskrit shlok
- Page 1 uses “With the blessings of God”.
- The Page 1 wax/mail icon and “Tap to open” label have been removed.
- Envelope opening video remains available as the initial opening interaction.
