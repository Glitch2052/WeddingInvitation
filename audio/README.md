# audio/

Drop your background song here and name it `wedding_song.mp3`
(already referenced in `index.html`'s `<audio>` tag).

**Playback timing:** the music starts automatically right when the
invitation page appears — i.e. once the envelope video has finished
playing and the screen has faded to reveal the site. It does not
play during the envelope video itself.

Keep it short and compressed (under ~3-4MB) so the site loads fast
on mobile — an MP3 at 128kbps is plenty for background music.

If you don't want music, no action needed — the sound toggle button
simply does nothing if `wedding_song.mp3` is missing.

This file just keeps the empty folder tracked by git — delete it
once you've added a real audio file.
