# images/particles/ — petal & flower art

The floating particle effect works today with a simple CSS-drawn
shape. To use your own art instead, drop in any of these filenames
(you don't need all of them — any subset works):

| File            | Suggested size |
|------------------|-----------------|
| `petal.png`      | ~60×60px, transparent background |
| `petal-2.png`    | ~60×60px, transparent background |
| `flower.png`     | ~60×60px, transparent background |
| `flower-2.png`    | ~60×60px, transparent background |

Each falling particle randomly picks one of whichever files you've
added, so mixing petals and small flowers together looks natural.
No code changes needed — just drop the files in.
