# images/

Add your own photos here, for example:

- `couple-1.jpg`, `couple-2.jpg` — engagement / pre-wedding photos
- `og-image.jpg` — a preview image (1200x630px) for a nice thumbnail
  when the link is shared on WhatsApp or social media

Once added, reference them in `index.html`, e.g.:

    <img src="images/couple-1.jpg" alt="Girl and Boy">

This file just keeps the empty folder tracked by git — delete it
once you've added real images.
