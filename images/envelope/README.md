# images/envelope/ — optional photoreal upgrade

The envelope works today with zero images (CSS gradients). Drop in
any of the files below and that layer automatically switches to the
real photo/graphic — no code changes needed.

| File               | What it is                                    | Suggested size     |
|---------------------|------------------------------------------------|---------------------|
| `back.jpg`          | Envelope back panel (behind the card)          | 1000×700px          |
| `front.jpg`         | Envelope front pocket (bottom triangle)        | 1000×700px          |
| `flap-outer.jpg`    | Outside of the top flap, as seen closed        | 1000×600px          |
| `flap-inner.jpg`    | Inside of the flap, revealed once it folds open| 1000×600px          |
| `card-texture.jpg`  | Subtle paper texture behind the invitation text| 800×1000px          |
| `seal.png`          | Wax seal graphic, **transparent background**   | 300×300px           |

## Where to get these

- **Freepik** (freepik.com) — search "wedding envelope texture" or
  "wax seal png transparent". Free tier requires attribution, Premium
  removes that requirement.
- **Envato Elements** / **Creative Market** — paid, but broad and
  license-clear for personal use like this.
- **Canva** — you can design/export your own envelope texture and
  wax seal directly as PNG/JPG.
- Commission a quick custom illustration (Fiverr etc.) if you want
  something that matches your reference images exactly — that
  quilted floral texture and floral wax seal look custom-made.

Whatever you use, double check the license allows the way you're
using it (a personal wedding site is usually fine even on free
tiers, but always worth a quick check).
